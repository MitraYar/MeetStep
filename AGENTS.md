# Работа над MeetStep

- Начинай с README.md и docs/PROJECT_STATUS.md. Полные требования — SPECIFICATION.md.
- Активная цель: Windows standalone секвенсор. LED-утилиты и VST3 заморожены; не менять их код и не выпускать новые билды без нового запроса пользователя.
- Управление/исследование пресетов устройства не входит в текущую работу. Музыкальные паттерны/сцены остаются частью спецификации.
- Сохраняй короткий актуальный статус, а не хронологию каждого эксперимента. Обновляй существующие документы вместо создания дубликатов, отчётов по каждому билду и новых handoff-файлов.
- Требования хранятся в спецификации, состояние реализации — в PROJECT_STATUS, рабочий LED-протокол — в docs/protocol/LED.md. Не копируй эти сведения по всему репозиторию.
- При изменении поведения удаляй устаревшие утверждения. Различай реализованное, локально проверенное и подтверждённое пользователем на Windows/SMK.
- Не коммить сырые захваты, временные логи, бинарники и генерируемые отчёты. Сохраняй небольшие fixtures, если они нужны регрессионным тестам.
- Не восстанавливай отвергнутые MIDI-транспорты; ограничения описаны в docs/protocol/LED.md.
- Интерфейс рассчитывай на Windows 11, 1600×900 с панелью задач; важные кнопки должны оставаться доступны.
