MeetStep Standalone — Windows x64

Распакуйте ZIP и запустите MeetStep Standalone.exe. Python и установка VST3
не требуются. Приложение отправляет MIDI; звук воспроизводит DAW/инструмент.

Settings:
1. Отметьте MIDI-входы SMK и нужных клавиатур.
2. Для нот и Clock выберите выход в DAW. На одном ПК можно создать виртуальное
   MIDI-устройство через loopMIDI и выбрать его входом в DAW.
3. Для подсветки выберите LED feedback device (выход SMK). Оставьте
   Wait for LED ACK выключенным: вход для подсветки не нужен. Для отключения
   подсветки выберите LED feedback disabled.
4. Нажмите Apply. Close закрывает настройки. Устройства выбираются заново
   после перезапуска. При недоступности устройства закройте MidiSuite и другие
   приложения, которые могут удерживать его MIDI-вход/выход.

DAW должна принимать внешний MIDI Clock. В Ableton включите Track и Sync
для входа от MeetStep, включите EXT и направьте MIDI на инструмент с Monitor In.
Не направляйте выход DAW обратно во вход MeetStep: это может создать MIDI-петлю.

Start начинает с шага 1; Stop гасит ноты; Continue продолжает.
Space и нижний правый пэд второй банки (note 63) CH10/CH11 — Play/Pause.
Slash ('/' EN, '.' RU) переключает Audition; comma/period ('б'/'ю') меняют
видимый диапазон нот. Клавиатурное управление действует при фокусе приложения.

Текущий прототип: 6 паттернов, 16 шагов, выход канала 1, gate в один шаг.
Пэды первой банки CH10 переключают шаги выбранной ноты. Ноту выбирают клавиатура
SMK или редактирование мышью. Левая кнопка рисует, правая стирает; drag — строка.
Velocity берётся из включающего нажатия пэда; мышь создаёт velocity 100.
Паттерны, velocity и BPM сохраняются при нормальном выходе.
Clear pattern / Clear all стирают сразу, Undo пока нет.

LED выбранной ноты: пусто — чёрный; velocity 127 — синевато-белый;
промежуточные значения — градиент. Подсвечиваются только 16 шагов банка 1.
Wait for LED ACK — необязательная диагностика. Для неё выберите вход SMK;
уже открытый игровой вход используется совместно. Только в этом режиме таймаут
ACK останавливает подсветку; для обычной отправки выключите опцию и нажмите Apply.
В обычном режиме доставка не подтверждается: проверьте цвет на контроллере.
Входящие SysEx не пересылаются и не вызывают изменение нот.
